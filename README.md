# Los Pros Racer 3D (MVP ejecutable)

Versión rápida de un juego de coches estilo pseudo‑3D hecho en **Python + Tkinter** (sin dependencias externas).

## Cómo jugar

```bash
python3 game.py
```

## Controles

- `W` / `↑`: acelerar
- `S` / `↓`: frenar
- `A` / `←`: girar izquierda
- `D` / `→`: girar derecha
- `R`: reiniciar cuando pierdes

## Objetivo

- Llega a la meta (`18000 m`) antes de que se acabe el tiempo.
- Pasar checkpoints te añade segundos y puntos.
- Evita chocar con el tráfico.

## Nota

Esta es una versión MVP jugable para empezar ya. Se puede evolucionar a un mundo más grande, garaje de coches, IA avanzada y versión 3D real con motor dedicado.
